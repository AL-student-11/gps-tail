# A learning project

## Overview
This program is a learning project that demonstrates how to work with GPS location data on SailfishOS device. It continuously receives GPS positions and maintains a trail of the user's recent movement. The trail is stored in a list and is limited to a maximum length of 1 kilometer, removing older location data as necessary.

## Technologies Used

QML - User interface

C++ - Logic
